# 実装・運用への対応（チーム側の確認事項）

確認日: 2026-09-22。以下は公式規定そのものではなく、[公式情報参照ガイド](README.md)をこのリポジトリで使うための確認項目。
チェック未記入は未確認を意味する。今回の資料整理では走行制御値や経路を変更していない。

| 観点 | 主な参照先 | 次に確認すること |
| --- | --- | --- |
| 速度上限・初期化 | `src/ypspur_ros2/config/default.yaml`、`src/ypspur_ros2/src/ypspur_node.cpp` | 通常上限1.0 m/s、実車paramのMAX_VEL=1.1 m/s。6 km/h未満でも誤動作時を含む仕様適合の証明にはならない。UI経由・独立IPC・実機側まで確認する |
| 非常停止 | 本体スイッチ、電源・ドライバ配線 | L1解放、cmd_vel=0、タイムアウト、UI停止と本体非常停止を区別。誤動作時・坂道・退避を実機で確認する |
| 自律／手動切替 | `src/drive_mode_manager`、`src/robot_console` | 本走行・記録・確認走行では操縦不能にする運用・接続を確認。画面表示だけでなく機体前後の色＋文字表示が必要 |
| 停止線・道路端 | `src/route_follower`、`src/robot_navigator`、`src/route_planner` | 中心点の到達だけで判定しない。車体全長・前後端・減速距離と停止領域を照合 |
| ゴール | 同上 | 車体全体の通過後に停止する条件と経路終端を確認 |
| 障害物と待機列 | `src/obstacle_monitor`、`src/robot_navigator` | 緑コーン検知、歩行者保護、追越し禁止、空きに追従、停滞時間を検証 |
| 信号横断 | `src/traffic_signal_recognizer`、`src/robot_console` | Bの実施有無を明示。B不実施でも信号・残留車両確認、再開操作、横断所要時間確認が必要 |
| RTK・環境 | `src/rtk_gps_um982`、`src/gnss_lio_fusion` | 補正サービスと現地基地局の設置位置を確認。選択Aを行う区域は事前計測対象から除外 |
| 車体外形 | `hardware_parts`、実機計測 | センサ・台座・配線を含む全高と本体高を区別。幅・長さ・重量・巻込み対策を実測 |
| 記録と報告 | `src/robot_console`、`src/route_survey` | 開始終了時刻、距離、失敗理由、達成段階、映像・ログの保管を確認。公開はユーザーの指定範囲で行う |

## 出走前に別途確認する項目

- [ ] 登録・入金・初回前日までの誓約書提出。
- [ ] 安全管理責任者とオペレータの2名、役割・服装・連絡手段。
- [ ] 9月20日版以降の最新シートによる当日の安全チェック。
- [ ] 確認走行認定と、構成変更による再認定の要否。
- [ ] 現地経路・通行範囲・停止領域・横断時間。
- [ ] 選択課題の実施申告、該当ラベル・機構の用意。
