# 走行システムの機能・制約と確認範囲

実機と模擬の共通起動、GNSS/LIO融合、経路採取・追従、手動介入、障害物監視、
車輪の速度・加減速度制御、時刻同期監視を提供する。
機能の存在と、現地での停止・通行性能は分けて確認する。

現在の機能・設定値・未実装の条件は[機能と制約](reviews/tc2026_software_20260922/README.md)に集約する。
初めて読むメンバーは次の順に参照する。

1. [システム構成](次期システム_アーキテクチャ検討レポート.md)：データと指令の流れ。
2. [共通起動](../src/icart_bringup/README.md)：実機・模擬とセッションの準備。
3. [実機ハードウェア統合](../src/icart_bringup/docs/実機ハードウェア統合.md)：接続・取付・Joy操作。
4. [機能と制約](reviews/tc2026_software_20260922/README.md)：停止状態、回避幅、未観測、位置品質の限界。
5. [公式情報参照ガイド](references/tsukuba_challenge_2026/README.md)：課題条件の原文と確認事項。

同梱経路やシミュレーションは現地確認済み本番経路の代わりにはならない。
