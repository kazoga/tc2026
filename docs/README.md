# docs 索引

ワークスペース全体に関わる文書の一覧である。文書の種別定義、章立て、記載粒度、配置規約は
[ドキュメント整備方針.md](ドキュメント整備方針.md) を正とする。

初めて読む場合は [走行システムの機能・制約と確認範囲](つくばチャレンジ2026_必須課題完走に向けた現状評価.md)
から入る。読む順序と各文書の位置づけを示している。

特定パッケージに閉じる文書は `src/<pkg>/README.md`（運用手順）と `src/<pkg>/docs/`（詳細設計書・
検討記録）にあり、ここには列挙しない。パッケージの一覧は
[ワークスペース README](../README.md) を参照する。
