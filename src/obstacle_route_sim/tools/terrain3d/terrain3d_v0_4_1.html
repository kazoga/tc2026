復元の根拠と調整

樹冠・屋根の自動推定は実測ではありません。confidence は相対的な候補スコアで、正解確率ではありません。森林補完は「推定」として記録します。高さの精度を上げるには同じ標高基準の DSM/DTM、形状には実際の 3D モデルを使用します。

取り込み形式・精度上の注意

仕様参照：国土地理院タイル / OSM 3D建物 / CityJSON。出典：© OpenStreetMap contributors / 国土地理院 / Esri World Imagery（利用したデータ源のみ）。

DTM/DSM は北西から東へ行優先の格子、標高 m、欠測 null。例：{"type":"TerrainRaster","w":2,"h":2,"bbox":[35,139,35.01,139.01],"verticalDatum":"orthometric","dtm":[10,10,11,11],"dsm":[10,18,11,20]}。dtm は必須。DSM と DTM は同じ座標・画素・撮影期・標高基準に揃えてください。

GeoJSON は WGS84 [経度,緯度]。properties.kind に building / tree / forest / water / road / rail / barrier / lamp / pole / bench 等、height・width は m。建物は中庭と roof:shape / roof:height を保持します。

CityJSON の MultiSurface / Solid 等の面形状を取り込みます。PLATEAU の CityGML / 3D Tiles は直接対応しません。CityJSON に変換し、対応座標系・同じ標高基準へ変換して読み込みます。EPSG 日本平面直角座標・GeometryInstance・CityJSONSeq・テクスチャは未対応。元モデルを OSM より優先します。

DEM の格子を細かくしても元測量の精度は上がりません。航空写真1枚から樹高・隠れた壁・細い電線を確定できません。屋根タグ未設定の建物は平屋根近似です。OBJ/USDA は改良形状を保持、SDF の衝突は簡略形状です。

設定

範囲と密度

範囲の一辺から推奨段階を自動選択（青行）。手動で上下に変更できる。注目領域は正規格子の切り出しです。精細化は全域の解像度と正規格子上限を変更してください。

範囲の一辺 m
段階一辺の目安ハイトマップ植生建物テクスチャ

ロボットのセンサ構成

構成に合わせて特徴量スコアの重みと、チェック・提案の内容を切り替える。ロボットごとに個別設定でき、複数台なら台ごとのスコアを表示する。

ロボット視点はプレビューです。現版は画像からの特徴点実測・センサ校正・SLAM実行を行いません。

海底地形の生成

粗い格子（450〜500 m）から直接三角形を張らず、一般的な海底起伏モデルで実現性に近い連続面を作る。

格子点を滑らかに通る曲面。直線（双一次）補間の折れ目・段差を出さない。

汀線 0 m から沖へ、砂浜は緩く・岩礁海岸は急に落ちる断面で、陸 DEM と連続につなぐ。海岸の土地被覆で A を切替。

傾斜が急な斜面ほど振幅を大きく、平坦な堆積面は小さく。振幅上限は格子の標準偏差以内に抑え、実測を上書きしない。

写真の青/緑バンド比で 0〜15 m の浅場を推定。格子より優先せず補間に混ぜる。透明度に依存するため既定オフ。

海図由来 XYZ / GeoTIFF があれば格子より優先。

変更はすぐに反映されます。

森・林の扱い

面積で指定した森林域に、樹種比・密度・樹高分布（例: 8〜18 m）でインスタンス配置。林縁は疎に、内部は密に。LiDAR では幹が点群の柱として現れ、衝突判定は幹のみ（樹冠は通過可の壁にしない）。

特徴量ヒートマップ

地表を tier に応じた格子で評価し、土地被覆の固定重みと地形勾配・鉛直構造の近接度を合成した参考スコア（ORB実測ではない）を表示。低スコア域はツールが黄色で警告し、岩・単木・轍の追加を提案する。
