# 障害物距離入力と停止判定

obstacle_distance_modeはhint（既定）またはscanを選ぶ。hintはfront_clearance_m、
scanは前方帯の距離を使う。非有限なhint距離はNoneに変換され、距離制約を適用しない。
したがって新鮮なメッセージでも、有効な障害物観測を保証しない。

obstacle_timeout_secは単体既定0で無効、共通実機起動は1秒で監視する。
障害物への制動は線速度に適用し、方位誤差が残る場合は旋回指令が残り得る。

現在の速度・制動式・監視条件・パラメータは[README](../README.md)を参照する。
制動・MotionLimitsの確認はtests/test_braking.pyとtests/test_motion_contract.pyで行う。
