# navigatorと経路追従の接続

route_followerがactive_targetを生成し、navigatorはpose・車輪速度・障害物距離からTwistを生成する。
共通起動では融合減速とmuxを経て車輪へ渡る。

followerの待機・完了状態と実測速度ゼロは別であり、目標再送の停止だけでnavigatorの保持目標は解除されない。
目標の受信期限を監視する仕組みはなく、follower停止時の指令失効は保証されない。

現在の速度・制動式・監視条件・パラメータは[README](../README.md)を参照する。
制動・MotionLimitsの確認はtests/test_braking.pyとtests/test_motion_contract.pyで行う。
