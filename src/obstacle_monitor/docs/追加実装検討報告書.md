# 障害物ヒントとセンサ表示

obstacle_monitorはLaserScanから前方閉塞、前方クリアランス、左右の回避オフセットを求め、
ObstacleAvoidanceHintへ格納する。navigatorは距離、followerは閉塞と幅を参照する。

前方距離は車幅帯内のx座標のパーセンタイルで求める。点数が不足する場合は
front_blocked=false・front_clearance_m=infとなり、未観測と空き領域を区別する品質フラグはない。
hint_range_mだけを大きくしても、max_obstacle_distance_mによる点群抽出範囲は広がらない。

sensor_viewerは点群・車幅・範囲・距離・回避幅・active_targetを表示する。
目標は自己位置とyawからローカル座標へ変換して描画する。
これは認識結果の可視化であり、旋回中の車体外周・後方・低い段差の通行性を保証しない。

トピック・パラメータ・起動例は[README](../README.md)を参照する。
有効な返りなし、全無効点、少数点、入力途絶を分け、hintと最終速度の両方を確認する。
