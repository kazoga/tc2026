# 道幅の区間確認ツール

## 役割

手動走行bagの前方映像と、既存の路面場・幅推定を並べて表示し、利用者が区間ごとに
道幅を判断して記入するための確認資料を作る。3本のツールで構成する。

| ツール | 入力 | 出力 |
|---|---|---|
| `tools/extract_route_frames.py` | waypoints_enu.json、bag | 経路距離ごとの前方映像JPEGと`frames.json` |
| `tools/render_width_panels.py` | `frames.json`、`surface_mask.npz`、`review_widths.csv` | 同じ地点の進行方向上向き俯瞰図PNG |
| `tools/build_width_review.py` | 上記2つの出力 | 記入用の単体HTML |

いずれもROSノードを起動せず、速度指令を出さず、bagと既存の解析結果を読むだけである。
記入結果を走行中の経路へ自動反映する機能はない。

## 前方映像の取得位置

カメラは車体前方を向いており、車体の真横の断面はほとんど写らない。
このため距離 s の断面を判断する映像には、s より `--lead` だけ手前で撮られたコマを使う。
既定は 8 m である。20 m 間隔で取り出すと、各コマが断面のおよそ 1 m 手前から 12 m 先までを
写すため、経路全体が切れ目なく覆われる。

映像はROS bagの `/usb_cam/image_raw`（`yuv422_yuy2`、640×480、5 fps）から、
waypointの記録時刻に最も近いコマを選ぶ。選んだコマと要求時刻の差は`frames.json`に残す。

## 俯瞰図の読み方

進行方向を上、車体から見た左を図の左に置く。映像と左右が一致する。

| 色 | 意味 |
|---|---|
| 緑 | 既存解析が路面候補とした格子 |
| 橙 | 段差・上方物体の候補 |
| 灰 | 観測はあるが路面候補ではない格子 |
| 白 | 未観測 |

青の三角と破線がカメラ位置、赤の実線が判断対象の断面である。断面上の緑と青の太線は
既存解析の左右退避候補を示す。これは参考値であり、記入欄の初期値には入れない。

格子は20 cmで、色のない場所を走行不可と断定したものではない。

## コーンの扱い

つくばチャレンジのコースは緑のロードコーンで区切られるが、同じ種類のコーンが
障害物としても置かれる。点群の格子からは両者を区別できないため、俯瞰図にコーンの
印は描かない。利用者が映像で、経路に沿って並ぶ境界のコーンか、単独で置かれた
障害物かを判断する。

記録したコーンと随伴者は記録日の配置であり、走行当日の配置ではない。
恒久的な道幅として記入する値には含めない。

## 実行

```bash
source /opt/ros/jazzy/setup.bash
python3 src/route_survey/tools/extract_route_frames.py \
  --waypoints <経路>/waypoints_enu.json \
  --run-cache <記録区間キャッシュ> --bag-root <bag置き場> \
  --output <出力>/frames --spacing 20 --lead 8
python3 src/route_survey/tools/render_width_panels.py \
  --frames <出力>/frames --surface-mask <路面場>/surface_mask.npz \
  --review-widths <幅推定>/review_widths.csv --output <出力>/panels
python3 src/route_survey/tools/build_width_review.py \
  --frames <出力>/frames --panels <出力>/panels \
  --review-widths <幅推定>/review_widths.csv --output <出力>/width_review.html
```

`--bag-root` は複数指定できる。記録区間ごとにbagの置き場が分かれている場合に使う。
bagが見つからない記録区間は、その旨を表示して対象から外す。

出力は生成物であり、リポジトリの管理対象には追加しない。

## 記入のしかた

HTMLをブラウザで開く。区間ごとに種別（歩道・広い／狭い・並ぶ／車道隣接／判断保留）を
選び、左右の幅を記入する。`j`・`k`で区間を移動、`1`〜`4`で種別、`c`で前区間の値を複製する。
入力はブラウザに自動保存し、CSVとJSONで取り出せる。JSONを読み込めば途中から再開できる。

CSVの`left_m`・`right_m`が利用者の判断値、`left_estimate_m`・`right_estimate_m`が
既存解析の参考値である。本番の経路CSVへ反映する手順は別に決める。
